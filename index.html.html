print(aluno1.notas)

Faça: crie aluno2 com dados diferentes.

Atividade 19 — Adicionando um comportamento Aplicar

class Aluno:
    def __init__(self, nome, notas):
        self.nome = nome
        self.notas = notas

    def calcular_media(self):
        return sum(self.notas) / len(self.notas)

aluno = Aluno("Carlos", [7, 8, 9])

print(aluno.nome)
print(aluno.calcular_media())

Observe: a classe possui dados (atributos) e ações (métodos).
